# Engineering Suite B2B

A single index with 28 connected tools: 13 thermodynamics modules, 4 McCabe workspaces, and 11 Mott modules.

## Publishing

1. Publish all contents while preserving the `cengel`, `mccabe`, and `mott` folders.
2. Place `ads.txt` at the public root of the domain.
3. Open `index.html` as the only navigation entry point.
4. Keep an internet connection available to load Tailwind, Chart.js, MathJax, jsPDF, html2canvas, and AdSense.

The calculations support preliminary engineering and must be verified for contractual or safety-critical design.
